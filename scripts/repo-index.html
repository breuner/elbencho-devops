elbencho packages

These are repositories for the latest stable packages for RHEL 8, 9 and 10, and for Ubuntu 24.04 and 26.04, on x86_64 and aarch64. The packages are built with S3_SUPPORT=1, SPDK_SUPPORT=1, IBVERBS_SUPPORT=1, RDMACM_SUPPORT=1, LIBFABRIC_SUPPORT=1 and BUILD_LIBFABRIC=1. The source code is in the elbencho repository.

RHEL, Rocky Linux, and AlmaLinux

The repository file selects the RHEL major version and the architecture.

1Save the repository file.

sudo curl -fsSL https://breuner.github.io/elbencho-devops/elbencho.repo -o /etc/yum.repos.d/elbencho.repo

2Install elbencho.

sudo dnf install elbencho

Ubuntu

The Ubuntu codename comes from the machine. Apt selects the architecture.

1Install the signing key.

curl -fsSL https://breuner.github.io/elbencho-devops/elbencho.gpg | sudo tee /etc/apt/keyrings/elbencho.asc >/dev/null

2Add the repository for this Ubuntu release.

echo "deb [signed-by=/etc/apt/keyrings/elbencho.asc] https://breuner.github.io/elbencho-devops/apt $(. /etc/os-release && echo $VERSION_CODENAME) main" | sudo tee /etc/apt/sources.list.d/elbencho.list >/dev/null

3Install elbencho.

sudo apt update && sudo apt install elbencho
